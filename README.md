## 🌟 Executive Overview

StudyOS bridges two demanding educational domains into a unified, privacy-first interface:
1. **Academic Excellence (Class 10 CBSE/NCERT)** — Physics, Chemistry, Biology, and Mathematics with interactive intuition builders, step-by-step mathematical proofs, NCERT question archives, and AI Socratic mentoring.
2. **Technical Interview Mastery (Software Engineering)** — System design, data structures & algorithms, full-stack frameworks (Laravel/PHP, Python, React/Node/TypeScript, AI/ML), live coding challenges with AST execution, and **voice-to-text AI answer synthesis**.

## ⚡ Core Application Features

### A. Interactive Mastery Learning Engine
- **Three-Tier Progression**: Every lesson is structured into *Physical Intuition*, *Mathematical Formulation & Units*, and *Exam Traps & NCERT Secrets*.
- **Interactive Understanding Gates**: Students must actively confirm comprehension at each block before the checkpoint quiz unlocks.
- **Formulas & Key Terms**: Live KaTeX equation rendering for complex formulas (e.g., $V = IR$, $\frac{1}{f} = \frac{1}{v} - \frac{1}{u}$, $\text{pH} = -\log[H^+]$).

### B. Explain Differently Multi-Pedagogy Studio
When a student struggles with a concept, they can switch between 4 distinct learning representations:
1. 💡 **Simple (5-Minute Plain English)**: Core definition with minimal jargon.
2. 🪔 **Indian Everyday Analogy**: Relatable real-world examples (e.g., water pipe resistance, cricket bowler velocity).
3. 📐 **Visual & ASCII Flowcharts**: Structured schematics depicting process flows.
4. 🇮🇳 **Smart Hinglish**: Conversational blend of Hindi and English for rapid intuitive grasping.

### C. Tech Interview Prep & Voice-to-Text Answer Studio
- **Microphone Dictation Hook (`useVoiceDictation`)**: Non-blocking speech recognition across 4 regional language profiles (`en-IN`, `en-US`, `hi-IN`, `en-GB`).
- **AI Answer Synthesis (`/api/ai/dev-interview-generate-answer`)**: Transforms disjointed spoken notes into polished, high-scoring interview answers.
- **Comprehensive Rubric Evaluation**: Analyzes candidate answers for Technical Correctness (40%), Architecture & Scalability (25%), Big-O Complexity (20%), and Communication Clarity (15%).

### D. Live Code Sandbox & AI Code Reviewer
- Pre-loaded coding challenges across **Laravel/PHP**, **Python**, **Modern JavaScript/TypeScript**, and **DSA**.
- AST syntax validation, custom test runners, and real-time execution outputs.
- In-depth AI code review breaking down time/space complexity, edge cases, and code style recommendations.

### E. 4-Level Confidence-Weighted Adaptive Practice
- Every question requires a confidence declaration:
  - **Very Confident (1.25x weight)**
  - **Confident (1.0x weight)**
  - **Somewhat Confident (0.65x weight)**
  - **Pure Guess (0.25x weight)**
- Promotes mastery only when correct answers are backed by high confidence, preventing lucky guesses from distorting proficiency scores.

### F. Spaced Repetition (SM-2 Algorithm) Flashcards
- Implementation of the SuperMemo-2 (SM-2) memory scheduling algorithm.
- Computes Easiness Factor ($EF$), interval repetition days, and review queues to optimize long-term memory retention.

### G. Strict CBSE Board Mock Exam Environment
- Timed board exam simulations matching official CBSE Class 10 patterns.
- Sectional division: Section A (MCQs & Assertion-Reason), Section B (Short Answers), Section C (Long Answers), Section D (Case-Based Scenarios).
- Auto-save timer and post-exam score report with step-by-step marking schemes.

### H. Cognitive DNA & Skill Heatmap Analytics
- Visual radar charts and heatmaps mapping 4 key cognitive dimensions:
  - **Recall & Factual Accuracy**
  - **Numerical & Algorithmic Application**
  - **Conceptual Synthesis**
  - **Exam Speed & Time Management**

### I. Parent & Guardian WhatsApp/Email Reporting Engine
- One-click export of structured student progress summaries.
- Pre-formatted for instant sending via WhatsApp Web or mail client (`mailto:`).
- Includes weekly study streaks, chapter completion percentage, and recommended review areas.

### J. Anti-Tamper Cryptographic Storage & Offline Resilience
- **HMAC-SHA256 Integrity Wrapping**: All LocalStorage data is signed with a cryptographic checksum to prevent local tampering of scores or streaks.
- **Graceful Fallbacks**: Fully operational in offline or low-bandwidth environments with intelligent mock data synthesis.

## 🛠️ Architecture & Tech Stack

```
├── StudyOS Frontend (React 19 + TypeScript + Tailwind CSS)
│   ├── Interactive Lesson Studio (KaTeX, Canvas Confetti, Lucide Icons)

│   ├── /api/ai/tutor (Socratic Study Assistant)
│   ├── /api/ai/explain-differently (Multi-Pedagogy Engine)
│   ├── /api/ai/dev-interview-generate-answer (Voice-to-Text Answer Engine)
│   ├── /api/ai/dev-interview-evaluate (Interview Rubric Scoring)
│   └── /api/ai/dev-code-review (AST & Big-O Code Analyzer)
│
└── Google Gemini API (@google/genai SDK)
    └── Model: gemini-3.7-flash (High-speed reasoning & JSON structured output)
```

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- NPM or PNPM

### Installation & Run

```bash
# 1. Install dependencies
npm install

# 2. Start the Full-Stack Development Server (Vite + Express on Port 3000)
npm run dev
```

Open your browser at `http://localhost:3000` to launch StudyOS.

### Build for Production

```bash
npm run build
npm start
```
